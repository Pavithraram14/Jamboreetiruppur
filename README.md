# Jamboree Events Website

A responsive, multi-page event-management website with an elegant dark-and-gold theme.

## Pages
- `index.html` — Home / landing page
- `about.html` — About the company
- `services.html` — Event services
- `gallery.html` — Photo gallery
- `careers.html` — Photographer vacancy and application form
- `booking.html` — Online event enquiry / booking form

## Run in Visual Studio Code
1. Extract `Jamboree_Events_Website.zip`.
2. Open the extracted `Jamboree_Events_Website` folder in VS Code.
3. Open `index.html` in a browser, or install the **Live Server** extension and choose **Open with Live Server**.

## Important setup before publishing
- Gallery and banner photos currently use remote Unsplash sample images. Replace these with the company's real completed-event photos. Add local images in the `images` folder if preferred.
- Booking and job forms use FormSubmit (`formsubmit.co`) to deliver submissions to `geethajamboreehr@gmail.com`. On the first submission, FormSubmit may send an activation email to that inbox. Open it and confirm activation. Test both forms after activation.
- This is a front-end website. For production-grade bookings, payment collection, admin dashboard, secure file uploads and database storage, connect a backend (for example, PHP/MySQL, Node.js, or a hosted form service).
- Verify all company details and vacancy information before publishing.
